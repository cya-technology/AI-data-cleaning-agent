# AI-data-cleaning-agent
An AI-powered data cleaning agent developed during an AWS Community Day Sacramento Hackathon on August, 2026. The agent helps transform cluttered spreadsheet data into a standardized format based on defined data requirements. Rather than automatically making changes without oversight, the solution incorporates a human review and approval step before data is finalized for database ingestion or migration.

**Problem the AI Agent solves:** 
Business data often needs to be cleaned and standardized before it can be migrated into a database or ERP system.

**The AI agent...**
Analyzes spreadsheet data, identifies inconsistencies, and proposes or performs cleaning actions based on requirements (Detailed in attached text file).

**Human Review is an Important Part of the Process**
The user reviews and approves the changes before the cleaned data is used, helping maintain accountability and data integrity.

**Technologies Utilized**
Visual Studio Code, Python, Streamlit, Pandas, OpenPyxl, Microsoft Foundry, Code Interpreter, SQL
